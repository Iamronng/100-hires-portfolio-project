# 100Hires Portfolio Project

## Overview
This repository documents my setup process for the 100Hires portfolio project. The goal is to show that I can install new tools, follow instructions, research problems, and document my process clearly.

## Tools Installed
- GitHub
- Cursor IDE
- Claude Code extension in Cursor
- Codex extension in Cursor

## Steps Completed
1. Created a GitHub account.
2. Created a public GitHub repository.
3. Installed Cursor IDE.
4. Connected Cursor with GitHub.
5. Opened the repository in Cursor.
6. Created and updated this README.md file.
7. Documented the tools installed, steps completed, issues faced, and solutions used.

## Issues I Ran Into
- I was new to GitHub and Cursor.
- I had trouble understanding how to connect Cursor with GitHub at first.
- My GitHub authorization session expired during setup.
- I could not find the repository folder on my computer at first.
- I learned that the repository existed online on GitHub, but it needed to be downloaded or opened locally in Cursor.

## How I Solved Them
- I followed the setup process step by step.
- When the GitHub authorization session expired, I restarted the connection process.
- I selected only the project repository when authorizing Cursor for safer permissions.
- I used the GitHub ZIP download method to open the repository in Cursor.
- I checked the README.md file in Cursor and updated the documentation.

## What I Learned
- A GitHub repository is an online project folder.
- A README.md file explains what the project is about.
- Cursor is an AI-powered code editor that can open and edit project files.
- Documentation is important because it shows the process, not just the final result.
